# Social media accounts for the monthly manual check

- **Why manual:** Instagram and X block bots in robots.txt, TikTok's terms ban automated
  extraction, and their APIs need accounts, applications or payment (register rows
  `instagram`, `tiktok`, `x`). Thomas checks these public profiles by hand once a month.
- **Where the handles come from:** Wikidata (CC0), read 2026-11-12 from each women's team's
  item page. Wikidata is edited by volunteers, so confirm each account is the official
  women's team account (verified badge, links from the club website) on the first check.
- **Gaps:** cells marked **missing** were not on Wikidata; please find and add them.
  VfL Wolfsburg's Wikidata item may be the wrong one (label is just "VfL Wolfsburg").
- **Log:** record each month's figures in `social_monthly_log.csv` (same folder), one row per
  club per platform. Leave a cell blank if the number isn't shown; never estimate.
